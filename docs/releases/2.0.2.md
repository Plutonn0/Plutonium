# Plutonium 2.0.2

- Maintenance now displays **MAINTENANCE MODE** and its reason to everyone, including owners and admins.
- Updated launchers and clients check every three seconds. Running clients block normal interaction and disable modules during maintenance.
- The launcher’s **Open admin menu** allows authorized recovery while normal navigation stays blocked. Admins and verified owners can stop maintenance; other global settings remain owner-only.
- In-game admins can stop maintenance from the blocking screen. Owners use their verified launcher session.
- A narrow, audited API action stops maintenance without changing its reason or disabled features. Revoked admins and ordinary users cannot use it.

Install this update in both the launcher and client. Older versions retain their previous maintenance behavior. Three-second polling is subject to network latency; this is not an instantaneous push notification.

Validation: 35 client tests, 79 launcher tests (3 optional Modrinth tests skipped), 24 API tests, and a native maintenance-navigation regression check passed. Live enforcement across multiple signed-in PCs was not exercised during this patch.
