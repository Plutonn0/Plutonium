# Plutonium launcher 2.0.4 — Closed beta

Hold Ctrl when starting Plutonium to enter a daily beta invitation. Enrollment stays with your Minecraft account until the owner revokes it, including after a restart or a new daily key.

The owner’s Moderation panel now includes Closed beta: copy the invitation, choose beta-only features, and revoke or restore members. Keys rotate at midnight UTC. Revoked users cannot re-enter with a new invitation. Beta access never grants admin powers or overrides account restrictions, maintenance, or globally disabled features.

All existing features remain public by default. This release adds enrollment and feature gates; private beta downloads are not configured. Client 2.0.2 is unchanged and honors beta restrictions through its existing policy heartbeat.

Validation: 34 API tests and 79 launcher tests passed; three optional live Modrinth tests skipped. Includes native WPF prompt rendering and blank-key validation. Real Microsoft enrollment and a PC restart were not automated.
