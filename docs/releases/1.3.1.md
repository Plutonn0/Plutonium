# Plutonium 1.3.1

- Active Modules HUD defaults to 65% size with tighter rows and padding. Long lists stay within roughly one third of the screen height and show a compact `+ more` count.
- Notifications default to 60% size, with narrower cards, smaller spacing and at most three visible notices. Titles and descriptions are retained.
- Both HUD modules have a **Size** slider in their right-click settings. Active Modules also has a **Maximum visible modules** setting.
- Existing configurations receive the new compact defaults automatically; other module settings are preserved.

Includes launcher and client 1.3.1 for Minecraft 1.21.11 / Java 21. Download **Plutonium.Client.exe**, or update both launcher and client from Settings → Updates.
