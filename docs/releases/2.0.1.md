# Plutonium 2.0.1

## Client and launcher fixes

- Center Modules HUD, notifications and coordinates vertically using the actual font bounds. Compact sizes and existing HUD size controls are preserved.
- Inventory Move keeps held movement keys active when closing the inventory, including mouse-bound movement keys. Typing, losing focus and unsupported screens still release injected movement.
- Clip the Play-page logo and artwork to its rounded frame at all supported window sizes.
- Update the launcher website link to plutoniumclient.vercel.app.

## Cloud moderation

Includes a Settings → Moderation & service status entry, owner/admin controls, maintenance screen, statistics, remote feature switches, restrictions, appeals and official-client policy handling, plus a separately deployable Vercel/PostgreSQL API.

The API and PostgreSQL database are deployed, the intended Microsoft owner identity is verified, and newly built launchers and clients embed the production endpoint. The website appeal page is connected to the API with Turnstile verification. There is no local email/password shortcut to owner access. This release remains a draft until live owner and client acceptance checks pass.

Follow `docs/moderation-setup.md` and `docs/moderation-api.md` before publishing an enforced build. Owner authentication pins verified Microsoft and Minecraft identities; delegated admins are limited to users/restrictions/appeals. Downloaded software can be modified, so no client-side mechanism can make bypass impossible.

The handoff package includes the backend, migration, Microsoft identity helper, API instructions, appeal-form example and 25 client / 25 launcher ideas. Ideas are proposals only, not implemented features.
