# Plutonium 2.0.1

## Client and launcher fixes

- Center Modules HUD, notifications and coordinates vertically using the actual font bounds. Compact sizes and existing HUD size controls are preserved.
- Inventory Move keeps held movement keys active when closing the inventory, including mouse-bound movement keys. Typing, losing focus and unsupported screens still release injected movement.
- Clip the Play-page logo and artwork to its rounded frame at all supported window sizes.
- Update the launcher website link to plutoniumclient.vercel.app.

## Cloud moderation

- Redesign the owner overview with live metric cards, 14-day activity and install charts, weekly comparisons, launcher versions and appeal review outcomes. Failed refreshes visibly mark existing values as stale.
- Give moderation sections their own views, with account-search and audit empty states.
- Redesign website appeals for desktop and mobile, with explicit field validation, CAPTCHA status/retry, request timeouts and readable failure references. Keep the explanation after a failed request. The owner confirmed a successful live submission.
- Align weekly analytics to UTC calendar days and prevent client heartbeats from overwriting launcher-version reporting.

Includes a Settings → Moderation & service status entry, owner/admin controls, maintenance screen, statistics, remote feature switches, restrictions, appeals and official-client policy handling, plus a separately deployable Vercel/PostgreSQL API.

The API and PostgreSQL database are deployed, the intended Microsoft owner identity is verified, and these launchers and clients embed the production endpoint. The website appeal page is connected to the API with Turnstile verification. There is no local email/password shortcut to owner access.

See `docs/moderation-setup.md` and `docs/moderation-api.md` for operation and remaining live acceptance checks. Owner authentication pins verified Microsoft and Minecraft identities; delegated admins are limited to users/restrictions/appeals. Downloaded software can be modified, so no client-side mechanism can make bypass impossible.

Validation: 35 client tests, 79 launcher tests and 23 API tests passed; three optional live Modrinth tests were skipped. Browser interaction checks and a human appeal submission succeeded. A full live in-game restriction/outage cycle has not yet been verified.

The handoff package includes the backend, migration, Microsoft identity helper, API instructions, appeal-form example and 25 client / 25 launcher ideas. Ideas are proposals only, not implemented features.
