# Plutonium 2.0.6 — HUD editor and live scoreboard editing

Open **F8 → HUD editor** to drag, resize and align Coordinates, Active Modules, Notifications and the Fake Stats sidebar. Positions adapt to screen-size changes and save automatically. Scroll or drag the lower-right handle to resize, use arrow keys for precise placement, and reset or hide individual elements. Hidden elements appear as previews without being enabled. The world continues running underneath the editor.

Right-click **Fake Stats → Edit current scoreboard** to detect your server's current sidebar and edit its title, labels and displayed values. The editor supports team-formatted rows, blank score formats, text selection and clipboard shortcuts. Local overrides persist per server and scoreboard while unedited values continue updating. Reset a row or all overrides to restore live values. The previous manual sidebar remains available by disabling Detect current scoreboard.

These edits change only what you see. They do not send commands or change server balances or statistics. If there is no sidebar, the editor explains that and provides Refresh entries. Unusual server text can be edited as a label if its embedded value cannot be separated automatically.

The editors use custom black-and-white controls, centered text, compact panels and the client's bundled high-resolution font. Both client profiles and the Windows launcher package are updated together.
