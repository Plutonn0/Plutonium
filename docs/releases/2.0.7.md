# Plutonium 2.0.7

Edit HUD now matches the client menu's dark styling, with centered text and a subtle hover animation.

Fake Stats automatically detects the active scoreboard sidebar and edits its displayed values locally inside Minecraft's original sidebar. It preserves the existing layout, row order and text colors without creating a replacement scoreboard or changing server data. Open F8, right-click Fake Stats, then choose **Edit current scoreboard**. The editor detects newly appearing or changed sidebars automatically; edits apply immediately and remain scoped to the server and objective.

Render distance resets to **32 chunks** and simulation distance to **24 chunks** on every game launch and world/server join. In-session adjustments remain possible; the next join reapplies these values. The FPS limit remains unchanged. Servers can still impose their own chunk-distance limits.

The obsolete custom Fake Stats panel and its manual display controls are no longer shown. The HUD editor continues to handle coordinates, active modules and notifications.

Validation: 48 client tests passed. Standalone and Fabric in-game checks passed, including live scoreboard detection, editing, server updates and resetting overrides. Both client profiles and the bundled Windows launcher were rebuilt.

**Updating from 2.0.62:** this release uses the requested version 2.0.7. Numeric version comparison considers it older than 2.0.62, so download and run the launcher asset manually; existing 2.0.62 launchers will not offer it automatically. The new launcher recognizes 2.0.61/2.0.62 as historical patches and can update their installed clients to 2.0.7.
