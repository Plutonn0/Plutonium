# Plutonium 2.0.0

A major launcher redesign, keeping the five main destinations: Play, Mods, Account, Files and Settings.

## A new launch dashboard

- Large branded Play panel with a dedicated launch strip and Standalone / Fabric selection.
- Account, installation and live download cards alongside the main panel.
- Quick access to your mod library, server favorites and updates.
- Refined monochrome typography, spacing, card surfaces and navigation, with a maximize / restore button.
- Layout checked at the default 1320 × 840 size and minimum 1120 × 740 size. The status column scrolls on smaller windows.

## Loading and feedback

- An animated startup screen appears before the dashboard, showing the actual setup stage.
- Installer file copying and Windows app registration run off the animation thread. Setup completes before the dashboard is revealed; setup errors still open the error report.
- Activity indicators on long-running actions, including mod installation, plus an always-visible footer status and a live download card.
- Smooth transitions and download progress based on actual transfer values. Paused and completed transfers stop their activity indicators.
- Startup, page and activity animations respect Windows' animation preference.

## Compact coordinates

- Coordinates HUD now defaults to 65% size with tighter padding and line spacing.
- Remains at the top left, with separate X, Y and Z lines and correct block coordinates.
- Right-click Coordinates in F8 to adjust its Size slider.

Includes launcher and client 2.0.0 for Minecraft 1.21.11 / Java 21. Download **Plutonium.Client.exe** or update both through Settings → Updates. Existing accounts, settings, worlds and mod files are preserved.
