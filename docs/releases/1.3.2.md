# Plutonium Launcher 1.3.2

- Fixes the empty "No compatible combination found" error for preview-only mods such as Reimagined Intro. The launcher now names the mod and explains when to enable **Include beta / alpha**.
- Reports missing dependency releases and conflicting exact versions instead of returning an unexplained failure.
- Adds **Browse** and **Your Mods** tabs inside Mods, keeping the five main sidebar pages.
- Your Mods shows managed, manually installed, unidentified and disabled mod files. Red **Uninstall** buttons remove third-party mods to a recoverable `mods/.removed` folder.
- Protects the bundled Plutonium client and checks local Fabric dependencies before uninstalling a required mod. Local jars can be uninstalled even if Modrinth cannot identify them.

Reimagined Intro's Fabric 1.21.11 releases are beta/alpha versions: enable **Include beta / alpha** in Browse before installing. Verified its dependency plan against the live Modrinth API with previews enabled. This does not guarantee every mod combination works at runtime.

Validated with **82 passing launcher tests**, including the live Reimagined Intro case, explicit resolver errors and recoverable local uninstallation.

Download **Plutonium.Client.exe** or update through Settings → Updates. Bundled client remains **1.3.1**, including the compact HUD and notifications.
