# Plutonium 1.2.0

Download **Plutonium.Client.exe** to install or update the Windows launcher. Includes the standalone and Fabric clients for **Minecraft 1.21.11 / Java 21**.

## Launcher

- Five main tabs: **Play, Mods, Account, Files, Settings**. Settings groups game preferences, appearance, server favorites, downloads, updates, rollback history and installation checks.
- Full-width Modrinth browser with search, categories, sorting and pagination. Each card offers **Install / Installed** and **View**.
- View opens the mod description, gallery, version and dependency information **inside the launcher**, without opening a browser.
- Automatically selects a compatible Fabric 1.21.11 release and installs required dependencies. SHA-512 verification, staged installation and conflict checks protect existing files.
- Detects existing jars by content hash, including renamed or disabled mods, and marks matching projects Installed. Exact matching local dependencies can be reused without downloading or renaming them.
- Installed-mod controls for updates, repair, enable/disable and removal. Removed files and externally modified files replaced during repair are retained for recovery.
- Custom monochrome RAM slider and dropdown menus.
- Persistent server favorites with quick joining; download progress and controls; installation health checks; update activity and verified rollback snapshots.

## Client

- Elytra Glide now supplies sustained, adjustable momentum without consuming rockets. Steer by looking; speed and acceleration are configurable.
- Render distance, simulation distance and FPS-limit changes are saved automatically and on normal shutdown.

## Updating

Existing launchers can update through their configured GitHub feed. This release includes both `launcher.json` and `client.json` with verified asset checksums.

Rollback snapshots begin with updates performed through launcher 1.2.0. Restoring a snapshot disables automatic updates so the selected version remains installed. Mod compatibility uses declared Modrinth metadata; it cannot guarantee that every combination of third-party mods works together.
