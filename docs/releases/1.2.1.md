# Plutonium Launcher 1.2.1

Fixes the "duplicates an installed mod ID" error when a mod installation requires a newer version of a manually installed dependency, such as Sodium.

- Identifies existing local jars by verified Modrinth file hashes, including renamed jars.
- Safely replaces an identified older version and keeps the original in the mods folder's `.replaced` recovery directory.
- Checks declared dependencies of identified local mods before upgrading; genuinely incompatible or unidentified files remain protected.
- Ignores repeated aliases within a single mod's metadata instead of reporting a false conflict.

Validated with 52 launcher tests, including a live Sodium 0.8.7 → 0.8.14 installation in an isolated folder. Existing user mods were not changed during testing.

Download **Plutonium.Client.exe** or update through Settings. The bundled Minecraft client remains **1.2.0** for Minecraft **1.21.11 / Java 21**.
