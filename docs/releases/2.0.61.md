# Plutonium 2.0.61 — Fake Pay message styling

Fake Pay now responds with `You paid Username $ Amount`, with only the dollar sign colored bright green (`#00FF00`). The wording and color appear in both chat and HUD notifications, including styled notification text when truncated.

Fake Pay remains a local simulation: no payment is sent to the server. This patch includes the updated Windows launcher and both standalone and Fabric clients.
