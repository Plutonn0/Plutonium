# Plutonium Launcher 1.3.0

## Custom controls

- Custom monochrome sliders with a larger drag target, animated handle, live value tooltip, keyboard controls and visible keyboard focus.
- Custom black-and-white scrollbars throughout the launcher, including mod descriptions and error reports. No extra sidebar tabs.

## Compatible mod installation

- Before installing, inspect existing jars and candidate releases, including nested Fabric mod metadata.
- Try alternative releases and dependency versions when a newer version conflicts with installed mods. Prefer retaining existing dependency versions where possible.
- Check declared Modrinth requirements, exact version pins, Fabric version ranges and hard incompatibilities in both directions.
- Preview selected versions inside the mod page; recheck before installing. Local mods recognized by hash can now be updated from their detail page.
- If no solution is found within the bounded search, explain the conflicting requirements and preserve the installation. No unrelated mods are automatically removed or disabled.

Compatibility checks rely on declared metadata. They cannot guarantee the absence of undeclared runtime conflicts. The planner checks up to 50 releases per project and 256 search states; Fabric Loader is installed separately when launching.

## Crash diagnosis

- Automatically inspect recent game output, the current launch's log and recent crash reports after an unexpected exit.
- Settings → Crash diagnosis also lets you analyze earlier logs.
- Show evidence, confidence and next steps for memory failures, dependency conflicts, failed mixins, graphics startup errors, Java mismatches, damaged archives and missing classes.
- Unknown crashes are labeled uncertain. A game crash no longer automatically labels the client installation as broken.
- Analysis runs locally. Reports are redacted and can be reviewed before using the existing opt-in Send error action.

Validated with **76 passing launcher tests**, including live Modrinth installation and Sodium upgrade checks, conflict backtracking, Fabric predicates, crash log freshness, redaction and native WPF control checks.

Download **Plutonium.Client.exe** or use Settings → Updates. Bundled client remains **1.2.0** for **Minecraft 1.21.11 / Java 21**.
