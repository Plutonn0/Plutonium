# Plutonium ideas — proposals only

None of the ideas below were implemented as part of the moderation work.

## Client — 25 ideas

1. **HUD magnet grid:** snap panels to each other and screen edges, with equal-spacing guides.
2. **Quiet gameplay mode:** collapse nonessential HUD elements during fights or screenshots, then restore them.
3. **Context profiles:** separate HUD/module presets for building, travel and practice, with a visible manual override.
4. **Session route journal:** a local map of where you travelled, with timestamps and named stops.
5. **Return-point compass:** point toward a manually marked location without revealing undiscovered terrain.
6. **Death recovery checklist:** remember your last death position and items you want to recover.
7. **Durability runway:** estimate remaining tool uses from your recent usage rate.
8. **Inventory fullness forecast:** warn before a mining or farming session fills your inventory.
9. **Container packing preview:** show how selected items would fit into your carried shulker boxes without moving them.
10. **Recipe shopping list:** track missing ingredients for a player-selected build or crafting plan.
11. **Build palette board:** pin block combinations and compare them under daytime/night lighting.
12. **Placement ruler:** a visual measuring tool for distances, symmetry and repeating patterns.
13. **Accessibility outlines:** configurable colors, thickness and patterns that remain distinct for color-blind players.
14. **Sound direction captions:** optional directional text for footsteps, explosions and other game sounds.
15. **Audio scene presets:** separate mixing presets for building, exploring and voice-chat sessions.
16. **Connection pulse:** show latency trends, jitter and brief connection interruptions with a tiny sparkline.
17. **Frame-time investigator:** identify stutters through frame-time spikes instead of only average FPS.
18. **Render-cost explorer:** estimate which visual settings have the biggest performance impact on this PC.
19. **Practice input overlay:** show your own key timing and click rhythm for reviewing recordings.
20. **Movement practice coach:** measure jumps, landing consistency and route timing in a local practice world.
21. **Elytra landing guide:** show an estimated descent path and warn about a steep approach, without controlling flight.
22. **Potion timeline:** display effect expirations as a compact time ruler rather than a stack of icons.
23. **Screenshot privacy preset:** hide coordinates, server addresses and player names before capture.
24. **Favorite commands wheel:** a configurable menu of commands you explicitly choose, with confirmation for destructive ones.
25. **Module dependency explainer:** explain why a module is unavailable, conflicting or restricted by service policy.

## Launcher — 25 ideas

1. **Launch rehearsal:** validate the next launch without opening Minecraft and show the first likely blocker.
2. **Mod change preview:** show exactly which files, dependencies and versions an installation will change.
3. **Disposable test profile:** try a mod combination in a separate profile before using your normal world.
4. **One-click mod bisect:** systematically isolate a crashing mod with explicit restart steps and progress.
5. **Profile health timeline:** record which mod/settings change preceded a new crash or performance regression.
6. **Offline readiness meter:** show whether every file needed for a selected profile is already downloaded.
7. **Download bandwidth schedule:** cap or pause downloads during user-defined hours.
8. **Metered-network mode:** require an explicit start for large downloads on limited connections.
9. **Disk-space forecast:** estimate temporary and final space before an update begins.
10. **Safe cache cleanup:** explain which cached files can be removed and how much space each group saves.
11. **Portable profile manifest:** export version references and settings without exporting account tokens or copyrighted game files.
12. **Pack drift detector:** flag local changes from a shared profile manifest and offer a reviewed resync.
13. **Release comparison:** compare two client versions by changed features, fixes and known issues.
14. **Trusted update verification:** display publisher-signature verification and detect unexpected update-feed changes.
15. **Staged updates:** opt into preview releases for one profile while keeping your main profile on stable.
16. **Recovery launch:** open a profile with a temporary minimal mod set and preserve the original configuration.
17. **World compatibility guard:** warn before opening a world with a version that could require conversion.
18. **World backup rotation:** keep scheduled local snapshots with clear storage limits and restore previews.
19. **Privacy report preview:** show exactly what an error/support report contains and let users remove sections.
20. **Account session health:** explain expired authentication, missing game ownership and service outages separately.
21. **Service incident timeline:** show confirmed launcher/authentication incidents and their current status.
22. **Personal launch diary:** a local history of profiles played, launch duration and crashes, with a clear-delete control.
23. **Mod accessibility filters:** discover mods by screen-reader, color, motion and input-accessibility features where metadata exists.
24. **Accessibility preview:** test font scaling, reduced motion, contrast and keyboard navigation before applying a theme.
25. **Appeal progress inbox:** let a restricted user check review status and receive a reviewer response without revealing other accounts.
